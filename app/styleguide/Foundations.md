# MusicLinkd Styleguide — Foundations

## Visual Design Philosophy
MusicLinkd is built on an editorial, high-contrast light aesthetic designed to let artist music, artwork, and photography lead the user experience.

### Core Foundation Rules
1. **24.dp Uniform Container Radius:** Every card, sheet, and modal container utilizes `RoundedCornerShape(24.dp)`.
2. **1.dp Crisp Border Line:** Cards use a thin `1.dp` solid border (`BrandBorder` `#ECECF1`) instead of heavy dropshadows.
3. **Generous Whitespace & Padding:** Minimum 16.dp to 20.dp internal content padding to ensure layout breathing room.
4. **Editorial Color Palette:**
   - **Primary Pink Accent (`BrandPrimary`):** `#EA4C89`
   - **Midnight Navy (`BrandDark`):** `#0D0B26`
   - **Soft Off-White Canvas (`BrandBackground`):** `#FCFCFD`
   - **Border Silver (`BrandBorder`):** `#ECECF1`
   - **Text Muted (`BrandTextSecondary`):** `#7D7D8E`
   - **Success Emerald (`BrandSuccess`):** `#10B981`
