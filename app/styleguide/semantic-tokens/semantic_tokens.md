# Styleguide — Semantic Tokens

## Semantic Color Mapping

- `colorSurface`: `Color.White` (`#FFFFFF`) — Base card fill color.
- `colorBackground`: `BrandBackground` (`#FCFCFD`) — Screen canvas background.
- `colorPrimaryAction`: `BrandPrimary` (`#EA4C89`) — Primary pill buttons and active tab icons.
- `colorBorder`: `BrandBorder` (`#ECECF1`) — Thin 1.dp border stroke for all card containers.
- `colorSuccess`: `BrandSuccess` (`#10B981`) — Verified artist checkmarks and connected state.
