# Styleguide — Spacing System

## 8.dp Spatial Grid

- `Space4`: `4.dp` — Micro gap
- `Space8`: `8.dp` — Standard inline padding
- `Space12`: `12.dp` — Card element spacing
- `Space16`: `16.dp` — Screen edge margin
- `Space24`: `24.dp` — Section gap & container corner radius
- `Space32`: `32.dp` — Top section padding
