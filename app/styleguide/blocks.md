# Styleguide — Structural Blocks

## Reusable Structural Layout Blocks

### 1. Base Container Block
- White canvas card (`Color.White`), `24.dp` corner radius, `1.dp` border stroke in `BrandBorder`.

### 2. Audio Waveform Player Block
- Animated audio waveform visualization with play/pause toggle button, time code display, and track title.

### 3. Media Gallery Grid Block
