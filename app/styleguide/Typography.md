# MusicLinkd Styleguide — Typography & Spacing

## Typography Scale
MusicLinkd utilizes Plus Jakarta Sans and system display typography pairings for high legibility:

| Token Name | Size / Line Height | Weight | Color | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **Display Title** | 28.sp / 36.sp | ExtraBold | `BrandDark` (`#0D0B26`) | Screen headers & hero banners |
| **Headline Medium** | 20.sp / 26.sp | Bold | `BrandDark` | Section titles & card names |
| **Body Large** | 15.sp / 22.sp | Normal / Medium | `BrandDark` | Bio paragraphs & feed content |
| **Body Small** | 13.sp / 18.sp | Normal | `BrandTextSecondary` | Location, instrument tags |
| **Caption / Badge**| 11.sp / 14.sp | SemiBold / Bold | `BrandPrimary` | Genre chips & verified labels |

## Spacing Grid
Built strictly on an 8.dp / 4.dp spatial scale:
- `4.dp` — Micro inline gaps
- `8.dp` — Standard chip & button padding
- `12.dp` — Card inner element spacing
- `16.dp` — Screen edge padding on compact displays
- `24.dp` — Section separators & container corner radius
- `32.dp` — Hero section top margins
