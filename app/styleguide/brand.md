# Styleguide — Brand Guidelines

## Brand Philosophy
MusicLinkd empowers independent music creators across three distinct environments:
- `musiclinkd.com` (Website)
- `app.musiclinkd.com` (Mobile & Web Application)
- `admin.musiclinkd.com` (Admin Operations)
- `https://github.com/wugweb-git/musiclinkd` (GitHub Source Code Repository)

High-contrast light layouts, generous whitespace, pill buttons, and `24.dp` rounded cards define the signature look.
