# Styleguide — Motion & Micro-Interactions

## Motion Guidelines

### 1. Tab & Screen Transitions
- Subtle fade-in and scale-in transitions using Jetpack Compose `AnimatedVisibility`.

### 2. Button State Feedback
- Ripple effect on touch press, instant state transition from `IDLE` to `PENDING` with checkmark icon scale animation.

### 3. Waveform Audio Indicator
- Loop animation for bar heights when audio preview is actively playing.
