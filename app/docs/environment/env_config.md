# Environment Configuration — MusicLinkd

## Product Target Hosts
- Website: `musiclinkd.com`
- App: `app.musiclinkd.com`
- Admin: `admin.musiclinkd.com`

## Secret Variables & BuildConfig Injection
Environment files (`.env.development`, `.env.staging`, `.env.production`) configure `GEMINI_API_KEY`, `FIREBASE_PROJECT_ID`, and `DEEP_LINK_HOST`.
