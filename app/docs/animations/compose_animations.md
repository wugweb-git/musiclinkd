# Compose Animations & Motion — MusicLinkd

## Animations Architecture

- **Waveform Equalizer:** Animated height bars driven by `rememberInfiniteTransition()`.
- **Screen Transitions:** Crossfade and slide-in animations via `AnimatedContent` and `AnimatedVisibility`.
- **Button Feedback:** Checkmark scale transition when connection request transitions from `IDLE` to `PENDING`.
