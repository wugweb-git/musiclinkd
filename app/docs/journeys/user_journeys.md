# User Journeys — MusicLinkd

## Primary End-to-End User Journeys

1. **Artist Session Booking Journey:**
   - User opens Discover screen on `app.musiclinkd.com`.
   - Filters by "Producers & Session Vocalists".
   - Selects Aditi Sen -> Inspects audio STEM waveform preview.
   - Click "Book Session" -> Chooses studio slot -> Confirms booking.

2. **Studio Slot Reservation Journey:**
   - User opens Studio Directory.
   - Chooses "Octave Sound Labs" (Bandra West, Mumbai).
   - Selects Dolby Atmos Suite -> Chooses 4-hour evening slot -> Submits booking request.
