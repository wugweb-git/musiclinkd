# User Types & Roles — MusicLinkd

## Supported User Roles (`app.musiclinkd.com`)

### 1. Solo Artists & Instrumentalists
- Session guitarists, vocalists, sitarists, drummers.
- Capabilities: Upload STEM previews, set hourly rates, accept connection requests.

### 2. Music Producers & Mix Engineers
- Electronic, pop, indie, film score producers.
- Capabilities: Post collaboration calls on feed, offer mixing/mastering services.

### 3. Recording Studios
- Commercial recording facilities (e.g., Dolby Atmos, SSL consoles).
- Capabilities: List hourly rates, equipment specs, manage reservation bookings.

### 4. Admin Users (`admin.musiclinkd.com`)
- System administrators and platform moderators.
- Capabilities: Verification badge management, content moderation, user metrics.
