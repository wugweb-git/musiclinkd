# Backend Integrations & Touchpoints — MusicLinkd

## Supported Cloud Services

1. **Firebase Authentication:** Email/password & Google One-Tap sign-in (`app.musiclinkd.com`).
2. **Cloud Firestore:** Real-time documents for users, connection requests, and networking feed posts.
3. **Firebase Storage:** Audio STEM snippets and artwork image gallery uploads.
4. **Firebase Cloud Messaging (FCM):** In-app & system push notifications (`AppNotificationManager`).
5. **Gemini 1.5 Flash API:** AI artist matchmaker and recommendation engine.
6. **Room Database:** Local SQLite caching for offline usability.
