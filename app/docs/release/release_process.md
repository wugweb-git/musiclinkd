# Release Process & Checklist — MusicLinkd

## Production Release Flow

1. Execute `compile_applet` clean build verification.
2. Verify Design System compliance (24.dp card corner radius, 1.dp borders).
3. Validate offline fallback data in `DemoDataProvider`.
4. Update `update.md` and `CHANGELOG.md`.
5. Tag git release (e.g., `v1.3.0`).
