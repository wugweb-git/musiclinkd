# Quality Assurance Plan & Test Cases — MusicLinkd

## Test Cases Matrix

1. **TC-001 Authentication & Snapshot Creation:** Sign-in with Google -> Verify user record created in Firestore and local Room cache.
2. **TC-002 Audio Waveform Preview:** Play audio STEM on artist profile -> Verify player progress bar animates.
3. **TC-003 Studio Booking Submission:** Select studio date/slot -> Submit reservation -> Verify success confirmation card.
4. **TC-004 Media Upload:** Click "Upload Media" -> Select file -> Verify Firebase Storage upload and UI refresh.
