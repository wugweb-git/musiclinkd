# ViewModel Architecture — MusicLinkd

## ViewModels & StateFlow Management

- `AuthViewModel`: Manages authentication flows, Google Sign-In, and user snapshot creation state.
- `OnboardingViewModel`: Manages multi-step role survey and interest selection.
- `DiscoverViewModel`: Manages search queries, category filter chips, and AI synergy matchmaker triggers.
- `ArtistProfileViewModel`: Manages profile state, media attachments upload, and connection request triggers.
- `StudioBookingViewModel`: Manages date/slot picker and booking submission state.
- `MessagingViewModel`: Manages active conversation messages and real-time push notification listener.
