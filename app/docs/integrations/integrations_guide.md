# Integrations Guide — MusicLinkd

## External Integrations Specification

1. **Google Identity & Firebase Auth:** User sign-in & JWT token validation.
2. **Gemini 1.5 Flash API:** AI artist synergy matchmaker and recommendation generator.
3. **Firebase Cloud Messaging (FCM):** Cross-device push notifications via `AppNotificationManager`.
4. **Android Media3 / ExoPlayer:** Real-time waveform audio preview playback.
