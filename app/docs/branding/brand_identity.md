# Brand Identity — MusicLinkd

## Product Hierarchy & Branding Guidelines
- **Public Portal (`musiclinkd.com`):** Minimalist editorial landing page introducing the MusicLinkd ecosystem.
- **Application (`app.musiclinkd.com`):** High-contrast light UI for music professionals, studio bookings, and session networking.
- **Admin Portal (`admin.musiclinkd.com`):** Enterprise control center for moderation, verified badge issuance, and analytics.

## Color Tokens
- `BrandPrimary`: `#EA4C89` (Dribbble Pink / Active Accents)
- `BrandDark`: `#0D0B26` (Midnight Navy / Primary Typography)
- `BrandBackground`: `#FCFCFD` (Soft Off-White Canvas)
- `BrandBorder`: `#ECECF1` (Subtle Silver Line)
- `BrandTextSecondary`: `#7D7D8E` (Muted Slate Caption)
- `BrandSuccess`: `#10B981` (Emerald / Connected Badges)
