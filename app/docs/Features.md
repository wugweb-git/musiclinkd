# Feature Specifications — MusicLinkd

## Core Modules & Feature Breakdown

### 1. Onboarding & Authentication
- Email / Password Login & Signup
- Google One-Tap Sign-In Integration
- Multi-step Role Selection (Artist, Producer, Studio, Label)
- Genre & Equipment Preference Survey

### 2. Networking & Discovery
- Discover Directory with category filters (Artists, Tracks, Studios, Projects)
- AI Synergy Matchmaker powered by Gemini 1.5 Flash
- Universal Search Bar with instant keyword query matching
- Verified Pro Badge validation

### 3. Artist & Studio Profiles
- High-resolution Unsplash photo portrait hero header
- Audio Waveform Player for STEM previews
- Gear & Equipment lists
- Media Attachments (Audio snippets & Behind-the-scenes gallery via Firebase Storage)
- Connection action button with live Firestore mutation feedback

### 4. Networking Social Feed
- Social update stream for posts, collaboration calls, and releases
- Inline audio waveform player
- Category filter chips (`COLLAB_CALL`, `RELEASE`, `STUDIO_UPDATE`)
- Post creation sheet with image/audio upload capabilities

### 5. Messaging & Inquiries
- Direct peer-to-peer messaging threads
- Session proposal cards
- Real-time message status indicators
- Room offline database caching

### 6. Studio Session Booking & Marketplace
- Hourly studio reservation slot picker
- Equipment rental listings
- Verified client review cards
- QR Code shareable talent profile canvas
