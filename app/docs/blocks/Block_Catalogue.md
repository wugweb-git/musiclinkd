# Block Catalogue — MusicLinkd Structural Layout Blocks

## Structural Layout Blocks

### 1. `ArtistProfileHeroBlock`
- **Purpose:** Full-width header block containing artist avatar, verified badge, location, genre chips, and action buttons.

### 2. `StudioSuiteSpecBlock`
- **Purpose:** Studio specification card listing console model, microphone locker, room dimensions, and hourly rate.

### 3. `AudioStemShowcaseBlock`
- **Purpose:** List block containing playable audio STEM preview tracks.

### 4. `SocialFeedPostBlock`
- **Purpose:** Social update card with media attachments, like button, and collaboration callout.
