Brand Kit

MusicLinkd

The professional network for music.
What this is, plainly: a single reference page assembling MusicLinkd's already-approved brand assets and documented values from frontend/guide/brand/README.md and frontend/guide/brand/assets/ — real logos, the two real brand colors, and the two real typefaces already in use. What this is not: no new logo variants, no invented color palette, and no AI-generated marketing imagery — there's no image-generation tool available in this session, so nothing here was synthesized. Every asset below is a file that already existed in this repo before this page was built.

Typography

Inter Tight for display, Inter for body — as documented. Loaded live from Google Fonts on this page. brand/README.md doesn't specify a size scale, so none is fabricated here; MusicLinkd System (../musiclinkd-system/) uses Gestalt's own type scale for that purpose.
