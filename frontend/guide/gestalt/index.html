Gestalt Library

Pinterest's Gestalt design system, vendored fresh into this repo as a standalone reference library. Separate from the existing style guide — nothing old was touched.

This page links out to source on GitHub for browsing. For a live, dynamic version — real components actually rendered and clickable, real design tokens, plus composed "Blocks" and a Foundations scale view — open MusicLinkd System → (needs to be served over HTTP; see its README/manifest entry for the one-line command).

About this library

This is a fresh, full vendor copy of Pinterest's Gestalt design system (source, docs, tokens, icons — 3,975 files, 34MB), stored under frontend/guide/gestalt/ as a new, separate reference library. It does not replace or modify the existing style guide at frontend/guide/styleguide.html.

Stack compatibility

AppStackGestalt status
/adminNext.js 15 + React 19.1Compatible — installed as a dependency
/webappVanilla HTML/JS PWANot compatible — Gestalt is React-only. Kept here for reference (tokens/icons can be hand-ported).
/frontend/websiteVanilla HTML/JSNot compatible — same reason.
Honest note: /admin already has its own component layer (shadcn/ui + Tailwind v4 + Base UI). Installing Gestalt makes its components importable there, but running two visual systems side by side risks style collisions and an inconsistent UI unless one is deliberately chosen for new work. Gestalt's global stylesheet (gestalt/dist/gestalt.css) was deliberately not imported app-wide for this reason — import it scoped to whichever route actually uses Gestalt.
