# Lucide — vendored icon set

GENERATED by `scripts/build-icons-lucide.mjs`. Do not hand-edit.

- **1653 icons**, extracted from `lucide-react@1.28.0` (ISC — see LICENSE).
- Stroked outlines on a 24 grid, `stroke-width="2"`, round caps and joins.
- `width`/`height` are omitted on purpose; the consumer sets size from `--icon-*`.
  The `viewBox` is always present, so scaling never crops.

## The two sets

This is the **breadth** set. `musiclinkd-system/icons/` is the **product**
set — 423 filled Gestalt glyphs, which is what app screens use.

Do not mix them inside one control or one toolbar. A filled glyph next to a
stroked one at the same size reads as two different weights.
