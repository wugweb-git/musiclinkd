# Design Principles 2.0 — MusicLinkd Product Operating System

These 10 measurable design principles govern every user interface decision across Web, Android, and Admin platforms.

---

## 1. Build Trust
Verified credits, confirmed studio availability, and identity badges take precedence over bio claims.

## 2. Reduce Cognitive Load
Editorial typography hierarchy, whitespace, and clean line gutters over crowded dashboard metrics.

## 3. Audio Before Text
Surfacing interactive audio waveform preview bars before long text descriptions.

## 4. Progressive Disclosure
Displaying primary CTAs first; secondary settings are surfaced in contextual bottom sheets.

## 5. One Primary Action
Exactly 1 primary pink pill button (`var(--pink)`) per container view to prevent decision paralysis.

## 6. Fast Thumb Reach
360dp mobile baseline with bottom sheet navigation for 1-hand thumb interaction.

## 7. Mobile First
Designed at 360dp reference frame before scaling up to 768dp tablet and 1024dp desktop.

## 8. Accessibility by Default
Minimum 48dp × 48dp touch targets and WCAG 2.1 AA contrast ratio (≥ 4.5:1).

## 9. AI Assists, Never Replaces
Gemini AI provides smart suggestions; human music professionals maintain 100% control over creative decisions.

## 10. Consistency Over Creativity
Reusing 1 canonical definition per component across all screens to guarantee high visual cohesion.
